# Deutero-ai Deutero-cli

## How do I install these formulae?

`brew install deutero-ai/deutero-cli/<formula>`

Or `brew tap deutero-ai/deutero-cli` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "deutero-ai/deutero-cli"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
